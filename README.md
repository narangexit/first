# 에어비앤비 입지 분석 리포트 생성기

월세 · 보증금 · 숙소 유형 · 사업 유형 · 역세권 거리 같은 기본 조건만 입력하면,
첨부 예시와 같은 형태의 **디테일한 에어비앤비(외국인관광도시민박업 등) 입지 분석 리포트**를
HTML로 만들어 주는 스크립트입니다.

- 스크립트: [`airbnb_report.py`](airbnb_report.py)
- 예시 결과물: [`sample_report.html`](sample_report.html)

## 무엇을 만들어 주나요?

생성되는 리포트에는 다음 섹션이 포함됩니다.

1. **종합 요약** — 종합 의견, 추천 점수, 예상 매출/순수익, 핵심 성공 조건·리스크
2. **지역 시장 구조** — 지역 성격, 방문 목적, 수요 요인, 체류 패턴, 계절성
3. **잘 되는 입지 / 안 되는 입지** — 추천·주의 입지와 판단 이유, 운영 포인트
4. **예상 수익 분석** — 객단가(ADR), 가동률, 월 매출/비용/순수익 추정
5. **추천 점수 산출 근거** — 교통·수요·수익성·운영 안정성·규제 적합성 (100점)
6. **타깃 · 운영 전략 / 리스크 · 체크리스트**

## 필요 환경

- Python 3.8 이상 (외부 라이브러리 불필요, 표준 라이브러리만 사용)

## 사용법

### 1) 명령줄 인자로 바로 생성

```bash
python3 airbnb_report.py \
  --room-type 투룸 \
  --rent 100 \
  --deposit 1000 \
  --business 외국인관광도시민박업 \
  --station-min 10 \
  --area 성내동 \
  --station-name 강동구청역 \
  --out report.html
```

생성 후 바로 브라우저로 열고 싶으면 `--open` 을 추가합니다.

```bash
python3 airbnb_report.py --room-type 투룸 --rent 100 --deposit 1000 --station-min 10 --open
```

### 2) 대화형(질문에 답하기) 모드

인자 없이 실행하거나 `-i` 를 주면, 항목을 하나씩 물어봅니다. (엔터만 치면 기본값 사용)

```bash
python3 airbnb_report.py
# 또는
python3 airbnb_report.py -i
```

## 입력 옵션

| 옵션 | 설명 | 기본값 |
| --- | --- | --- |
| `--room-type` | 숙소 유형 (`원룸` / `투룸` / `쓰리룸`) | `투룸` |
| `--rent` | 월세 (만원) | `100` |
| `--deposit` | 보증금 (만원) | `1000` |
| `--business` | 사업 유형 (예: `외국인관광도시민박업`, `생활숙박시설`, `농어촌민박`) | `외국인관광도시민박업` |
| `--station-min` | 역에서 도보 시간 (분) | `10` |
| `--area` | 지역명 | `성내동` |
| `--station-name` | 인접 역명 | `강동구청역` |
| `--out` | 저장할 HTML 파일 경로 | `report.html` |
| `--open` | 생성 후 브라우저로 열기 | (없음) |
| `-i`, `--interactive` | 대화형 입력 모드 | (없음) |

## 질문 주신 조건으로 생성한 예시

> 투룸 · 월세 100만원 · 보증금 1000만원 · 외국인관광도시민박업 · 역에서 10분

```bash
python3 airbnb_report.py --room-type 투룸 --rent 100 --deposit 1000 \
  --business 외국인관광도시민박업 --station-min 10 --out sample_report.html
```

결과 요약(예시):

- 추천 점수: **84점 / 100점 (추천)**
- 예상 월 매출: **205만~378만원**
- 예상 월 순수익: **42만~226만원**

전체 결과는 [`sample_report.html`](sample_report.html) 를 브라우저로 열어 확인하세요.

## 계산 기준을 바꾸고 싶다면

객단가·가동률·비용 가정은 `airbnb_report.py` 상단의 표만 수정하면 결과가 바뀝니다.

- `ROOM_PROFILE` : 숙소 유형별 기준 객단가/인원
- `BUSINESS_PROFILE` : 사업 유형별 객단가 보정·합법성 점수
- `_station_occupancy()` / `_station_score()` : 역세권 거리에 따른 가동률·점수

> ⚠️ 객단가·가동률 등은 입력 조건 기반 **추정치**입니다.
> 실제 계약·인허가 전에는 주변 동급 숙소의 예약 캘린더, 성수기/비수기 편차,
> 외국인관광도시민박업 등록 요건(주택 유형·면적·소방 등)을 반드시 직접 확인하세요.
